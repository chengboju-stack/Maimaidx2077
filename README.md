# 网页布局学习专题

《可视化导论》课程作业。结构参考 https://cinger007.github.io/vis/ ，内容为独立编写的网页布局教程，不是教师官方章节。

## 作业定位

老师要求制作一个讲解“网页页面布局”的 Lesson，每小节有文字讲解、关键代码和 Demo。录音 00:57 的“当成第六个 Lesson”用于说明参照关系；本作品作为独立专题展示，首页是学习目标与目录，小节从 1 编号，不暗示另有五章待完成。

## 内容

六节：布局原则与视觉层级、盒模型、Flexbox、Grid、响应式布局、综合案例。每节都有文字讲解、关键代码、交互实验。统计数据均为演示数据。

## 本地运行

直接用浏览器打开 `index.html` 即可学习，所有课程资源都是本地文件，不需要 npm 或 CDN。

也可以在本目录启动静态服务器：

```sh
python -m http.server 8080
```

然后访问 http://localhost:8080 。剪贴板复制功能依赖浏览器许可，推荐 localhost 或 HTTPS；复制失败时可手动选择代码。

## 免费发布到 GitHub Pages

1. 创建公开仓库，将本目录中的 `index.html`、`styles.css`、`design.css`、`app.js` 放在仓库根目录。
2. 打开 Settings → Pages，选择 Deploy from a branch。
3. 选择 main 分支、/(root) 目录并保存。
4. 等待部署成功，使用 Pages 页面显示的网址访问。

如果把整个项目上传、网站仍位于 work1/site，则访问发布地址后的 `/work1/site/`，或者将网站文件移到发布根目录。所有本地资源使用相对路径，支持项目子路径部署。

顶部前五章链接会跳转到老师的实际网站。本地教学和实验不依赖这些外链，参考资料需要网络。发布操作尚未执行。

## 交互说明

- 左侧目录及上一节/下一节切换小节，URL 中保存小节编号。
- 三个标签支持左右方向键、Home、End 切换。
- 每节实验可修改参数并重置。
- 响应式实验使用隔离的 iframe 视口和真实 CSS 媒体查询，640px 为本例断点。
- 盒模型实验用有颜色的外层包装模拟 margin 区域，计算中单独统计外间距。
- 综合仪表盘是便于对比的缩略示意；代码页给出完整页面的窄屏布局方案。
